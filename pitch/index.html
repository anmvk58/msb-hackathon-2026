HACKATHON 2026 · FINANCIAL INTELLIGENCE

25 giây. FinSen là Financial Sensing. Ý tưởng lấy cảm hứng từ nguyên lý sensing trong hỗ trợ lái xe: liên tục quan sát tín hiệu để nhận ra rủi ro sớm. APPENDIX 02 / DEPLOYED ARCHITECTURE

1 VPC. 1 subnet. 4 vServer. 1 RDS.

Mobile Frontend là điểm vào duy nhất từ bên ngoài. Các service và cơ sở dữ liệu giao tiếp qua mạng nội bộ.

Phụ lục, chỉ trình bày khi có câu hỏi. Hệ thống nằm trong một VPC. Bốn vServer Mobile Frontend, Core Banking Service cùng Admin Web Control, FinSen Agent cùng Scheduler, và PostgreSQL cùng nằm trong một subnet. Chỉ Mobile Frontend có public endpoint để người dùng mở ứng dụng qua HTTPS. Mobile gọi Core và Agent qua mạng nội bộ; Agent gọi Core API và PostgreSQL qua mạng nội bộ. RDS MySQL của Core Banking có private endpoint trong VPC. FinSen Agent chủ động gọi ra GreenNode MaaS qua HTTPS để dùng model GLM-5.2; đây là kết nối outbound, không phải đường truy cập từ Internet vào Agent. Core, Agent, PostgreSQL và RDS không nhận truy cập trực tiếp từ bên ngoài.
